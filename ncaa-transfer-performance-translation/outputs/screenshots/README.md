# Analysis screenshots

The seven Google Colab analysis screenshots are embedded directly in the project-level `README.md` using GitHub attachment URLs so they render immediately for portfolio viewers.

The same analyses are reproducible from code:

- `src/eda.py` generates the EDA charts from the committed demo data.
- `src/visualize_results.py` generates team-profile, transition, model-comparison, and feature-importance charts after model training.

This folder is kept as the presentation-screenshot index while the actual screenshots render in the main README.
