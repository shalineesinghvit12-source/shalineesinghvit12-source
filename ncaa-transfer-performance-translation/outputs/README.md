# Outputs

This folder contains lightweight portfolio outputs that make the project understandable without opening the code.

## Committed outputs

- `model_metrics.json` — last committed demo model comparison results
- `transition_summary.csv` — aggregate pre/post transfer results by transition type
- `screenshots/team_environment_profiles.jpg` — Google Colab K-means Low/Medium/High profile view
- `screenshots/kmeans_elbow_method.jpg` — Google Colab elbow-method reasonableness check

## Generated when the pipeline is run

`python run_pipeline.py` also generates:

- `team_profiles.csv`
- `transfer_modeling_table.csv`
- `model_bundle.joblib` (ignored by Git)
- `team_profiles.png`
- `transition_analysis.png`
- `model_comparison.png`
- `feature_importance.png`

The screenshots are presentation artifacts. The reproducible plots are generated by `src/visualize_results.py` from the pipeline outputs.

All committed model results are demonstration results from synthetic NCAA-like data unless the pipeline has explicitly been retrained and validated on real historical data.
